# Decisions

- 2026-10-30: Python 3.10.11 venv in `.venv/` (created with `py -3.10`); `requirements.txt` pins direct dependencies only (transitive ones are resolved by pip).
- 2026-10-30: Code is run as modules (`python -m src.x.y`) from the repo root; `__init__.py` files added to `src/` packages and `tests/`.
- 2026-10-30: `results/raw/` and `results/plots/` are git-ignored (regenerable); `results/tables/`, `results/summary.json` and `data/instances/` are tracked.
- 2026-10-30: `make` is not installed on this Windows machine; Makefile targets are kept as specified and each is a single `python -m ...` command that can be run by hand.
- 2026-10-30: NFZ centres are drawn so each polygon lies fully inside the map (centre in [R, 10-R]); this keeps detours from leaving the map. No clipping is needed.
- 2026-10-30: NFZ vertices are hull points with radius uniform in [0.6R, R] around the centre. The 5-20% total-area rule is enforced by redrawing the whole NFZ set (up to 200 times); instances with 0 NFZs are exempt.
- 2026-10-30: Holes in merged NFZ unions are filled (exterior ring only); the visibility graph does not model free pockets inside NFZs.
- 2026-10-30: Polygon vertices are pushed outward by 1e-6 km along the corner bisector, so NFZ detours are up to a few 1e-6 km longer than the exact value. A segment is blocked if it intersects the NFZ union (touching counts), which is safe because of the push.
- 2026-10-30: Unreachable distances are stored as `null` in JSON and loaded back as `inf`.
- 2026-10-30: Generator RNG is `np.random.default_rng([seed, attempt])`; generation is deterministic. Repairs are logged at INFO to `data/generation.log` (git-ignored candidates: not yet ignored, file is regenerated by `make data`).
- 2026-10-30: Clustered and corridor targets are clipped to [0, 10] with no margin; only uniform uses the 0.3 km margin, as specified.
- 2026-10-30: `small_test` (seeds 1000-1019) is the same set of instances as the first 20 of `test` (1000-1099), as the spec says. Debugging on `small_test` therefore touches 20 test instances; noted as a limitation.
- 2026-10-30: `Solution` and the `timed()` wrapper (perf_counter around `solve()` only) live in `src/baselines/solution.py`, so checker/metrics do not import baseline code.
- 2026-10-30: Routes hold target indices only, so "route ends at the wrong depot" cannot occur there; `checker.check_node_sequences` checks routes given as full node sequences (depots included) for that case.
- 2026-10-30: Checker leg test: the rebuilt path must match `dist` within 1e-6 km and have at most 1e-9 km inside the NFZ union. `check(..., check_paths=False)` skips this for speed.
- 2026-10-30: Do not pass threads= to PuLP's CBC: with the bundled CBC 2.10.3 on Windows it hangs on the MILP (found on the N=5 test model; without it the same model solves in <1 s). CBC uses its default thread setting.
- 2026-10-30: OR-Tools arc costs are rounded UP to metres (spec says round) and capacity is floor(B*1000), so any route within capacity is within B in real km and passes the checker; legs longer than B+1 km are capped to keep the matrix finite. GLS has no seed argument in this API; it is deterministic for fixed inputs.
- 2026-10-30: MILP uses arrival-distance variables t[i,k] with big-M propagation (bounds d[k,i]..B-d[i,k]) instead of MTZ order variables, plus pruning of arcs/visits that cannot fit in B. With MTZ, CBC reached only 15-63 of ~100 weight after 60 s on test_small_n seeds 4000-4002; the new form proved seed 4000 optimal in 7 s. Tuned on test_small_n only, as allowed.
- 2026-10-30: lawnmower is a single pass over the strip order (a skipped target is not revisited later). MAP_SIZE=10 is a constant in lawnmower.py.
- 2026-10-30: 'smoke' excludes MILP (300 s per instance would break the <1 min target); MILP is run on test_small_n only. Makefile smoke target updated.
- 2026-10-30: Routes are not stored in the result CSVs, so plots re-solve greedy, lawnmower and ortools_5s on the plotted instances; plot titles show the CR of that re-solve (OR-Tools may differ slightly from the CSV because it is time-limited).
- 2026-10-31: results/raw and results/plots are tracked in git (small, and they are the evidence for the README tables); this supersedes the earlier note that ignored them.
- 2026-10-31: notebooks/pilot_demo.ipynb added as the pilot demonstration (classical methods only until the GNN exists). src/eval/plots.py now selects the Agg backend only inside main(), so the notebook can show figures inline.
